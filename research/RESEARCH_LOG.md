# 研究日志：“好记”算法的递归改进

## 定义（2026-10-06，研究开始前固定）

好记 = 同样的学习时间下，7 天后能**双向**还原单词的概率（看词 → 想起意思；想到意思 → 写出拼写），且不和邻居词串。
每张卡片可计算的预测量：N 块数、K 熟块覆盖、I 具体度、S 语义桥、U 未锚定的拼写风险位、D 干扰、T 词表内复用。
真值分层：第 0 层 公开语料（免费、客观）→ 第 1 层 重建测试 → 第 2 层 盲评 → 第 3 层 真人延迟测试（唯一真值，需要人）。

本轮自主研究只能拿到第 0、1 层。凡是需要第 3 层才能下结论的地方，日志里明确标出。

## 协议

- 词按 md5 固定切分：dev 60% / val 20% / hidden 20%（`common.split_of`）。hidden 只有 `FINAL=1` 时可读，统计表也排除 hidden 词。
- 每轮：在 dev 上看失败 → 提一个假设 → 只改一处 → dev 上比较 → 过了再看 val → 接受或回滚。
- 数据（`research/data/`）不进 git：FCE 许可仅限非商业研究，并且只允许公开不超过 100 词的原文片段。
  数据来源须引用：Yannakoudakis, Briscoe & Medlock (2011)，A New Dataset and Method for Automatically Grading ESOL Texts，ACL。

## E0：拼写风险位（U）对不对？

**真值**：已知某人把 w 拼错了，错在哪个字母上。
- FCE（剑桥 FCE 考生，多国学习者）的 R:SPELL 编辑：4,526 个事件。
- Birkbeck 拼写错误语料（以母语者为主）：19,074 个事件。用作第二人群，检验结论能不能迁移。
- 过滤条件：词长 ≥ 4，在 CMUdict 里，错拼与正确词的编辑距离 ≤ 2。

**指标**：位置级 AUC，分两种口径：pooled（按事件加权）、word-macro（每个词等权）。

### 第 0 轮：基线（dev）

| 方法 | FCE pooled / macro | Birkbeck pooled / macro |
|---|---|---|
| 随机 | 0.504 / 0.506 | 0.501 / 0.500 |
| 元音字母 | 0.555 / 0.547 | 0.564 / 0.589 |
| wordseg 现有风险标记（B0：不规则、不发音、弱读） | 0.558 / 0.566 | 0.579 / 0.598 |
| p2g 意外度 −log P(字母组合 \| 音素) | **0.605 / 0.617** | **0.618 / 0.664** |

- 结论：wordseg 现在标出的风险位，在学习者身上几乎等于“元音字母”这条朴素规则。
- p2g 是从 3 万个高频词的对齐结果里统计出来的“这个音一般怎么写”，换成它之后提升明显，而且两个人群上方向一致。
- 顺带修了一个 bug：有些读音的音素比字母多，`wordseg.align` 对不齐就崩溃，常见词里有 347 个受影响，比如 security。现在允许一个字母对应两个音素；实在对不齐就丢掉这个读音。
