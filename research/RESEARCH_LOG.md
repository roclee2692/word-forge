# 研究日志：“好记”算法的递归改进

## 定义（2026-10-06，研究开始前固定）

好记 = 同样的学习时间下，7 天后能**双向**还原单词的概率（看词 → 想起意思；想到意思 → 写出拼写），且不和邻居词串。
每张卡片可计算的预测量：N 块数、K 熟块覆盖、I 具体度、S 语义桥、U 未锚定的拼写风险位、D 干扰、T 词表内复用。
真值分层：第 0 层 公开语料（免费、客观）→ 第 1 层 重建测试 → 第 2 层 盲评 → 第 3 层 真人延迟测试（唯一真值，需要人）。

本轮自主研究只能拿到第 0、1 层。凡是需要第 3 层才能下结论的地方，日志里明确标出。

## 协议

- 词按 md5 固定切分：dev 60% / val 20% / hidden 20%（`common.split_of`）。hidden 只有 `FINAL=1` 时可读，统计表也排除 hidden 词。
- 每轮：在 dev 上看失败 → 提一个假设 → 只改一处 → dev 上比较 → 过了再看 val → 接受或回滚。
- 数据（`research/data/`）不进 git：FCE 许可仅限非商业研究，并且只允许公开不超过 100 词的原文片段。
  数据来源须引用：Yannakoudakis, Briscoe & Medlock (2011)，A New Dataset and Method for Automatically Grading ESOL Texts，ACL。

## E0：拼写风险位（U）对不对？

**真值**：已知某人把 w 拼错了，错在哪个字母上。
- FCE（剑桥 FCE 考生，多国学习者）的 R:SPELL 编辑：4,526 个事件。
- Birkbeck 拼写错误语料（以母语者为主）：19,074 个事件。用作第二人群，检验结论能不能迁移。
- 过滤条件：词长 ≥ 4，在 CMUdict 里，错拼与正确词的编辑距离 ≤ 2。

**指标**：位置级 AUC，分两种口径：pooled（按事件加权）、word-macro（每个词等权）。

### 第 0 轮：基线（dev）

| 方法 | FCE pooled / macro | Birkbeck pooled / macro |
|---|---|---|
| 随机 | 0.504 / 0.506 | 0.501 / 0.500 |
| 元音字母 | 0.555 / 0.547 | 0.564 / 0.589 |
| wordseg 现有风险标记（B0：不规则、不发音、弱读） | 0.558 / 0.566 | 0.579 / 0.598 |
| p2g 意外度 −log P(字母组合 \| 音素) | **0.605 / 0.617** | **0.618 / 0.664** |

- 结论：wordseg 现在标出的风险位，在学习者身上几乎等于“元音字母”这条朴素规则。
- p2g 是从 3 万个高频词的对齐结果里统计出来的“这个音一般怎么写”，换成它之后提升明显，而且两个人群上方向一致。
- 顺带修了一个 bug：有些读音的音素比字母多，`wordseg.align` 对不齐就崩溃，常见词里有 347 个受影响，比如 security。现在允许一个字母对应两个音素；实在对不齐就丢掉这个读音。

### 第 1 轮：逻辑回归组合特征（dev 按词分组 5 折交叉验证）

- 读音类特征（p2g、silent、schwa、dbl、irr）组合后：FCE 0.626，比单用 p2g 的 0.600 高。
- 再加上位置先验（vowel、relpos、edge）：FCE 0.656。位置先验说的是“首字母很少拼错、越靠后越容易错”，这是真实规律，但和读音无关，单独记一笔。

### 第 2 轮：失败聚类 → 竞争拼法压力 comp

- **失败聚类**（FCE，dev）：模型低估了三类位置。
  - 双写辅音（ll、pp、nn、tt，错误率 0.27–0.37）；
  - 多字母组合里“多出来”的字母（wh 里的 h，错误率 0.44）；
  - 拼法相互竞争的组合（ei→/iː/ 错误率 0.67，ar→/ɚ/ 0.43）。
  - 共同原因：p2g 只给整个字母组合打分，说不出组合里**哪个字母**危险。
- **假设**：对每个字母，计算同一个音的其他写法里，有多少概率恰好在这个字母上和它不同（comp）。
  - 例：/w/ 最常写 w，所以 wh 的风险落在 h 上；/l/ 常写 ll，所以单写的 l 也带一点“可能写成两个”的风险。
- **结果**：

| 方法 | dev-cv FCE | val FCE pooled / macro | val Birkbeck pooled / macro |
|---|---|---|---|
| wordseg 原风险标记 B0 | 0.558 | 0.559 / 0.542 | 0.572 / 0.594 |
| p2g | 0.600 | 0.605 / 0.617 | 0.615 / 0.662 |
| **comp 单特征** | 0.623 | **0.638 / 0.644** | 0.628 / 0.690 |
| 全特征逻辑回归 | 0.659 | **0.666 / 0.666** | 0.660 / 0.722 |

- 加入 comp 后，“弱读”特征的系数降到约 0（val 上 −0.04）。说明弱读元音的风险，本质就是“这个音有多种写法”，comp 已经完整覆盖。
- **接受 comp**：它在 val 上是最好的单一特征，能指出具体哪个字母、会被写成什么，适合直接放到卡片上。全特征模型多出来的约 0.03，主要来自位置先验；先不进产品，避免过度拟合语料的特性（P07）。

### 接入产品：wordseg 输出“易错位”

- `scripts/p2g.json`（6 KB）：“读音 → 拼写”统计表，只由 CMUdict + wordfreq 算出，不含任何学习者语料，可以公开。
- 阈值 0.5，在 dev 上选定：

| 标记 | 标出的字母比例 | 这些位置的错误率 / 平均错误率（val，FCE） |
|---|---|---|
| 旧：弱读 / 不规则 / 不发音 | 32% | 1.30× |
| 新：comp ≥ 0.5 | 23% | **1.58×** |

  标得更少，命中却更高，两方面都更好。
- 输出示例：`which` → 易错位：wh 的 h（/w/ 也常写成 w）；`accommodate` → mm 的 m（也常写成单写 m）。
- 顺带修好重音符位置（/fˈrɛnd/ → /ˈfrɛnd/）。原来 10 个回归词的切分结果完全不变。
- 已知遗留问题：
  - friend 的 ie 没被对齐成一个组合（字母组合表里没有 ie→/ɛ/），所以这个经典易错位漏掉了；
  - fri | end 被误标 ★：fri 是高频缩写，被当成了熟词。留到 E3 的“学习者画像”里统一处理。

## E2：碰撞检测（D）能不能列出学习者真实混淆的词？

**真值**：FCE 里“把一个真词错写成另一个真词”的编辑。
- 过滤掉屈折变化、英美拼法差异和语法类错误（单复数、时态、介词）。
- 写成的词须为常见词（zipf ≥ 3）；“形近”定义为只差一个字母，或读音几乎相同（音素距离 ≤ 1）。
- 定义是在看过 dev 噪声后定下的：一类是 wich、freind 这种非词错拼，另一类是 have←make 这种选词错误。定下后不再改动。
- **指标**：召回率，即学习 c 时，碰撞栏是否列出学习者实际写成的 o。每个词最多列 4 个（与原实现相同）。

| 版本 | dev 召回（194 对） | val 召回（62 对） | 平均每词列出 |
|---|---|---|---|
| v0 原版：只看编辑距离 1，按词频排序 | 0.61 | 0.47 | 2.8 |
| A：加近音邻居，按词频排序 | 0.61 | — | 3.5 |
| B：加近音邻居，同音 +1.5、近音 +0.8 | 0.60 | — | 3.5 |
| **C：只收同音和“只差一个元音”的邻居** | **0.66** | **0.58** | 3.1 |

- **失败分析（A/B）**：只差一个音素的邻居太多，比如 which 旁边冒出 with、watch、wish，把真正命中的词挤出了名额。
- **C 的依据**：真实混淆的近音词对，差别几乎都在元音上（accept/except、sell/sale、seats/sits），辅音不同的很少被混淆。
- **接受 C**。新找回的典型例子：break↔brake、waste↔waist、peace↔piece、principle↔principal、whether↔weather。
- **局限**：
  - val 只有 62 对，+0.11 的置信区间很宽；
  - stationery 太低频，没过 zipf 门槛；
  - 偶尔混进非英语词，比如 loose ↔ los。

### 顺带修复：wordseg 第二个崩溃

- 原因：贪心对照里，前一块熟词停在一个多字母组合的中间时，找不到从下一个位置开始的组合，程序崩溃。
- 修复后，常用 2 万词全部跑一遍，崩溃 0 次。

## E3a：词根词缀说法的真实度（Fidelity，不误导）

**测试词表**：从 KyleBing/english-vocabulary 的雅思词表（BSD-3）里，按事先写死的规则抽 1000 词。
- 条件：纯字母单词、在 CMUdict 里、≥7 个字母、zipf ≤ 3.8；满足条件的 1777 词里用种子 42 抽取。
- 切分：dev 621、val 203、hidden 176。

**真值**：MorphoLex-en 的人工语素切分（Sánchez-Gutiérrez et al., 2017），覆盖其中 979 词。

**指标**：wordseg 第 1 名路径里被标成前缀/词根/后缀的块，两端是否落在真实语素边界上。
- 只在 MorphoLex 切成 ≥2 个语素的词上算；边界允许 ±1。
- 事先定下的目标函数：正确数 − 2 × 错误数。一条误导性的词源，代价是一条正确说法价值的两倍。

| 轮次 | dev 正确 / 错误 | 目标 | val 正确 / 错误 | 容差准确率 val | 决定 |
|---|---|---|---|---|---|
| 基线 | 297 / 64 | 169 | 97 / 25 | 0.80 | |
| H-M1 剥离检验 | — | — | — | — | **拒绝**：砍掉的 83 条里有 44 条是对的；词干多是不在词表里的黏着词根 |
| **H-M2 MorphoLex 可信度过滤（τ=0.4）** | 268 / 14 | **240** | **87 / 5** | **0.95** | **接受** |
| H-M3 链式支持（低可信度但挨着可信语素就保留） | 267 / 30 | 207 | — | — | **拒绝** |

- **H-M2**：在 6.8 万个 MorphoLex 词里（测试词全部排除）统计每个串真是语素的比例。
  - 例：ac- 0.31、em- 0.34、secu 0.30、-ity 0.92、-ment 0.87。
  - 前缀不在词首、后缀不在词尾时，可信度打五折。
  - 导出到 `scripts/affix_rel.json`，只包含汇总比例，并注明出处。
  - τ 在 dev 上用目标函数选出：0.25 → 207、0.3 → 222、0.35 → 231、**0.4 → 240**、0.45 → 238、0.5 → 236。
- **H-M2 的代价**：obnoxious（ob|nox|ious）、accommodate（ac|com|mod|ate）这类真词源被拆散；entrepreneur 丢了 pren（拿）。
- **H-M3 的教训**：它是为了救回上面这几个词想出来的，在这几个例子上有效，在 dev 整体上却让错误翻倍。**凭几个回归词的直觉改代码，整体是负收益。**
- **口径局限**：MorphoLex 标的是现代英语构词（secure+ity），word-forge 看重历史词源（ad+com+mod）。accommodate 这类词在 MorphoLex 里是单语素，所以它们的词源切分对不对，这个指标判断不了。要解决需要词源级真值（比如 Wiktionary 的词源切分），列为后续工作。

## E3b：★ 的定义（K，熟块覆盖）——定义修正，不是可度量的改进

**问题**：旧 ★ 的条件是“每块都在 wordfreq 高频词里”。
- dev 的 271 条 ★ 路径（前 3 名）里，**81%** 含有通用学习者不认识的块，按 raelon 画像算也有 65%。
- 典型假熟块：ive、ent、tic、comm、cont、rep、nes、fri。它们只是缩写或词缀碎片，wordfreq 收录它们是因为出现频率高。
- 后果：SKILL.md 里排第一的选择规则“★ 默认当主记法”，大部分 ★ 是假的。

**修正**：★ 要求每一块都在学习者画像的词表里，看块的全部身份（ant 被标成后缀，也照样算熟词）。
- `general`：初中 + 高中词汇（3,901 词）。
- `raelon`（默认）：在 general 基础上加四级词汇（+1,750），再加德语、法语高频词。
- 词表来自 KyleBing/english-vocabulary（BSD-3），导出为 `scripts/known_en.json`。

**结果**（dev，第 1 名带 ★）：raelon 14%，general 8%。
- 例：blueprint = blue|print，campfire = camp|fire，counterpart = counter|part，ascertain = as|certain。
- redundant 在 raelon 画像下仍是 ★；在 general 画像下不是，因为 und 只对学德语的人算熟块。wednesday、friend 不再带 ★。

**为什么不算“改进”**：真值本身就是这份词表，拿它来评自己是循环论证。这一步修的是定义，不是用数据证明“更好记”。
**已知偏差**：课程词表偏保守，比如 berry 不在 general 里，所以 strawberry 在 general 画像下没有 ★。

## 总结

**已经证明的**（第 0 层真值：学习者错误语料、人工语素标注）：
1. 卡片上的“⚠ 风险位”现在能更准地指出学习者真会拼错的字母。
2. “⚔ 先分清”能找回更多真实的易混词，比如 break/brake、principle/principal。
3. 误导性的词源说法减少约三分之二。
4. 程序不再崩溃。

**没有证明的**：
- 以上任何一项是否让人**记得更牢**，也就是 7 天保留率有没有提高，都需要第 3 层的真人测试。这轮研究没有做。
- ★ 的修正是定义层面的，不是度量出来的改进。
- 具体度（I）和语义桥（S）还没有任何真值，所以这次没有动。

**方法上的教训**：
1. 凭几个回归词的直觉做的修补（H-M3），放到整体数据上是负收益。每个改动都要过 dev 和 val。
2. 指标口径要在看结果之前定好。E2 的真值定义和 E3a 的目标函数都是先写死再调参，调整也都记在日志里。
3. 用来当真值的标注本身有立场：MorphoLex 标的是现代构词，不是词源。指标测得准，不代表测的就是我们要的东西。

**下一步最值得做**：
1. 第 3 层真人测试：新旧卡片随机分配，1 天和 7 天后各默写一次。这是唯一能回答“好记”的数据。
2. 词源级真值（Wiktionary 的词源切分），用来校准 E3a 的口径偏差。
3. 把 ie/ei 这类组合补进对齐表，让 friend 这类经典易错位也能被标出来。
