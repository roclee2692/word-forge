# 雅思听力：字母O /əʊ/  vs 数字0(oh)
【听觉事实】二者读音完全一致，仅靠听力无法区分。

## 英国邮编 Postcode 硬性规则
1. 邮编分为两部分，中间带空格： 外向码  内向码
   内向码（空格后面）：格式固定【数字+字母+字母】
   ✅ 空格之后：**禁止使用字母 O、I、V**
   → 空格后听到 /əʊ/，只能写数字 0

2. 外向码（空格前面）可以出现数字0；字母O现实极少。
   - 音频只简单读 oh → 写数字 0
   - 音频明确说出：letter O / O as in orange → 才写大写字母 O

## 配套坑点：字母I vs 数字1
- 只听到 /aɪ/，无补充说明 → 写数字 1
- 听到 letter I → 写大写字母 I

## 考场直接执行口诀
听到 /əʊ/
① 如果在邮编空格后面 → 写 0
② 没有说 letter O → 写 0
③ 只有明确强调 letter O → 写大写 O
